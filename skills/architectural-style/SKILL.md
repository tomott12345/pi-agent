# Skill: architectural-style

Generates a Substack-ready note about a specific architectural style: its history, key characteristics, representative image, and a tip for further learning. Works with any era and style, including residential, landscape, and interior designs. Outputs a formatted Markdown post with image link and a learning tip.

**Usage:** Provide style name (e.g., "Art Deco", "Mediterranean", "Brutalist") and optionally a country or region. The skill will generate a post with a historical overview, visual reference, and a tip to explore the style further.

**Example:** "mediterranean villa italy" → generates a post with image of a villa, history, and tip: "Read the book *Mediterranean Architecture* by ...".

**Output:** A Markdown file ready for Substack, containing:

- Title: "Exploring [Style]"
- Brief history
- Key features
- Image link (URL to representative image)
- Learning tip
